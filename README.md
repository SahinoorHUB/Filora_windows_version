## Install

1. Download the `.7z` archive for your version.
2. Extract the archive (Windows 10/11 built-in support, or [7-Zip](https://www.7-zip.org/)).
3. Run `Filora.exe`.

**Requirements:** Windows 10 or 11 (64-bit).
